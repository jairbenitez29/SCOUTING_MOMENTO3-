Scouting deportivo

Plataforma de apoyo analítico para clasificar perfiles de futbolistas a partir de edad, estatura y posición mediante un modelo Random Forest entrenado con datos de mercado.

Integración con API REST Resultados en tiempo real

Resumen del sistema

El modelo fue entrenado con 41.495 registros válidos y un umbral de élite definido por el percentil 75 del valor de mercado. La interfaz se comunica con FastAPI por medio del endpoint POST /predict.

Modelo de clasificación Random Forest
Fuente de datos MySQL / CSV

Propósito analítico

Brinda una estimación estadística para apoyar procesos de scouting, sin sustituir la valoración técnica o la decisión final de fichaje.

Uso responsable

La salida debe interpretarse como una probabilidad de pertenecer al grupo Élite y no como una certeza absoluta sobre el desempeño futuro del jugador.
